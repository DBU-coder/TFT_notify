# 🤖 ESP32-C3 ANCS Smart Display & RoboEyes

Компактный настольный информер на базе **ESP32-C3 SuperMini** и цветного TFT-дисплея **ST7735** (1.8", 128×160). Устройство подключается к iPhone по Bluetooth Low Energy (BLE), дублирует входящие уведомления с поддержкой кириллицы, синхронизирует точное время и отображает анимированные глаза робота в режиме ожидания.

---

## ✨ Возможности

- **Интеграция с iOS (Apple ANCS):** мгновенный прием заголовков и текста сообщений из любых приложений (Telegram, мессенджеры, SMS, системные уведомления) без установки сторонних программ на телефон.
- **Циклическая карусель истории:** хранение до 10 последних уведомлений в кольцевом буфере с автоматическим переключением каждые 10 секунд. Новые сообщения вытесняют самые старые.
- **Двусторонняя синхронизация:** при смахивании или прочтении уведомления на iPhone оно автоматически удаляется из карусели на экране.
- **Поддержка кириллицы и умный перенос:** корректное отображение украинского и русского алфавитов (`UTF-8` → `Win-1251`) с расчетом ширины символов в пикселях, переносом по словам и эффектом **печатающей машинки**.
- **Анимированный режим ожидания (RoboEyes):** плавная 40 FPS анимация глаз без мерцания (с использованием буфера `GFXcanvas16`). В активном режиме глаза голубые и «оглядываются» по сторонам, при потере связи с телефоном — становятся оранжевыми с прикрытыми «сонными» веками.
- **Синхронизация времени (BLE CTS):** автоматическое получение точного времени с iPhone по протоколу Current Time Service и вывод часов в правом верхнем углу.
- **Управление звонками:** базовый прием или отклонение входящего вызова через Serial Monitor (`1` — принять, `0` — сбросить).

## 🛠 Аппаратная часть и подключение

### Компоненты

- **Микроконтроллер:** ESP32-C3 SuperMini
- **Дисплей:** 1.8" TFT LCD SPI (контроллер ST7735, разрешение 128×160)

### Схема подключения (Hardware SPI)

| Пин дисплея ST7735 | Пин ESP32-C3 | Описание             |
| :----------------- | :----------- | :------------------- |
| **VCC**            | `3.3V`       | Питание дисплея      |
| **GND**            | `GND`        | Общий провод         |
| **CS**             | `GPIO 10`    | Chip Select          |
| **RESET (RST)**    | `GPIO 4`     | Аппаратный сброс     |
| **A0 (DC)**        | `GPIO 3`     | Выбор данные/команда |
| **SDA (MOSI)**     | `GPIO 7`     | Линия данных SPI     |
| **SCK (SCLK)**     | `GPIO 6`     | Тактовый сигнал SPI  |
| **LED (BLK)**      | `3.3V`       | Подсветка матрицы    |

## 📂 Структура проекта

Код разделен на логические модули для удобства поддержки и расширения:

```text
ANCS/
├── ANCS.ino               # Главный файл: инициализация и основной цикл (loop)
├── config.h               # Пины подключения, настройки таймеров, геометрия глаз и UUID
├── NotificationQueue.h    # Кольцевой буфер для хранения и управления очередью уведомлений
├── DisplayUI.h            # Отрисовка интерфейса, перенос текста, печатная машинка, RoboEyes и часы
└── BleAncsClient.h        # Работа с NimBLE, парсинг пакетов ANCS (включая длинные) и CTS
```

## 📦 Зависимости (Библиотеки)

Для компиляции проекта в **Arduino IDE** установите следующие библиотеки:

1. **ESP32 Board Package** (версии 3.x) в Менеджере плат.
2. **NimBLE-Arduino** (версии 2.x) — для работы с BLE, шифрованием и протоколами ANCS/CTS.
3. **Adafruit GFX Library** — базовый графический движок и буфер `GFXcanvas16`.
4. **Adafruit ST7735 and ST7789 Library** — драйвер дисплея.
5. **Ukr_GFX_fonts** — шрифты с поддержкой кириллицы (в проекте используется `segoeuiUkr6.h`) и утилита перекодировки `utils.h`.

## 🚀 Установка и первый запуск

1. Склонируйте репозиторий или скачайте все файлы в папку `ANCS`.
2. Откройте `ANCS.ino` в Arduino IDE.
3. В настройках платы выберите **ESP32C3 Dev Module** (при необходимости включите _USB CDC On Boot: Enabled_ для вывода логов в Serial Monitor).
4. Скомпилируйте и прошейте плату.
5. На iPhone откройте **Настройки $\rightarrow$ Bluetooth**, найдите устройство **`TFT-Notify`** и нажмите для подключения.
6. Подтвердите запрос на создание пары (**Создать пару**) и обязательно разрешите передачу системных уведомлений (**Разрешить**).

## ⚙️ Настройка под себя

Все основные параметры вынесены в файл `config.h`:

- `QUEUE_SIZE` — максимальное количество уведомлений в карусели (по умолчанию `10`).
- `SHOW_TIME_MS` — время показа одного слайда в миллисекундах (по умолчанию `10000` мс = 10 сек).
- `TYPE_SPEED_MS` — скорость анимации печатной машинки в мс на символ (по умолчанию `15` мс).
- `SPI_FREQ` — частота шины SPI дисплея (по умолчанию `27000000` Гц для плавной анимации без мерцания).
